# 📖 Docs Share 使用指南

欢迎使用 Docs Share！这是一个简单但强大的 Markdown 文档分享系统。

## 🚀 快速开始

### 本地浏览

1. 将 `.md` 文件放入 `docs/` 目录
2. 运行 `npm start`
3. 访问 http://localhost:3457

就这么简单！

## ✨ 核心功能

### 1. 搜索文档

- 使用侧边栏顶部的搜索框
- 支持搜索文档标题、内容描述和文件名
- 实时过滤显示结果
- 按 `ESC` 清除搜索

### 2. 刷新文档列表

点击搜索框下方的"刷新"按钮，无需刷新页面即可加载新添加的文档。

### 3. 下载文档

每个文档右上角都有下载按钮，可以下载原始 Markdown 文件。

## 📡 远程更新

### 使用 CLI 工具

最简单的方式是使用命令行工具：

```bash
# 初始化配置
npx docs-share init

# 编辑 .docsrc.json 填入服务器地址和 API Key

# 上传文档
npx docs-share upload my-doc.md
```

### 使用 API

发送 POST 请求上传文档：

```bash
curl -X POST http://localhost:3457/api/docs \
  -H "Authorization: Bearer dev-key-change-in-production" \
  -H "Content-Type: application/json" \
  -d '{
    "filename": "api-test.md",
    "content": "# API 测试\n\n这是通过 API 上传的文档！"
  }'
```

### Git Webhook

1. 将文档仓库托管在 GitHub/GitLab
2. 设置环境变量 `ENABLE_WEBHOOK=true`
3. 在 GitHub/GitLab 配置 webhook 指向 `/api/webhook`
4. 每次 push 自动更新！

## 🤖 AI 集成

### 场景：AI 写完文档自动发布

```javascript
// AI 生成内容
const content = generateWithAI(prompt);

// 自动上传
fetch('http://localhost:3457/api/docs', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer your-api-key',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    filename: 'ai-generated.md',
    content: content
  })
});
```

或者更简单：

```bash
# AI 输出到文件
ai-tool generate > output.md

# 一键上传
npx docs-share upload output.md
```

## 🎨 自定义

### 修改主题

编辑 `docs/index.html` 中的 CSS 变量：

```css
:root {
    --bg-deep: #080b10;
    --accent: #638cff;
    /* 修改这些变量来自定义主题 */
}
```

### 修改端口

设置环境变量：

```bash
PORT=8080 npm start
```

或在 `.env` 文件中：

```
PORT=8080
```

## 🔒 安全

**重要！** 生产环境务必：

1. 更改默认 API Key
2. 使用 HTTPS
3. 配置防火墙
4. 不要在文档中放敏感信息
