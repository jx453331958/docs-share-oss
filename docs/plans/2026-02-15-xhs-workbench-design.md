# 小红书工作台设计

## 需求

docs-share-oss 目前只支持扁平 `.md` 文件列表，无法查看小红书工作流产出的 HTML slides + PNG 图片 + 配文。需要一个专属页面方便查阅。

## 数据源

- `xhs-index.md` — 文章索引
- `xhs-{slug}/README.md` — 每篇文章元信息（slug、标题、日期、状态、风格、slide 数量）
- `xhs-{slug}/slide*.html` — HTML 源文件
- `images/xhs-{slug}/slide*.png` — 渲染后的图片
- `xhs-{slug}-*.md` — 发布稿（配文 + 图片引用 + 信息来源）

## 页面设计

### 列表页 `/xhs`

- 三个状态分组：📝 草稿 → 📤 待发布 → ✅ 已发布
- 每组内按日期倒序
- 卡片内容：封面图（slide1.png 缩略图）+ 标题 + 日期 + slide 数量
- 空状态组自动隐藏
- 暗色主题，延续现有风格

### 详情页 `/xhs/{slug}`

- 顶部：标题 + 状态标签 + 日期 + 风格
- 中间：竖版 slides 依次排列（宽度 390px 模拟手机），点击放大原图
- 底部：配文正文 + 一键复制按钮
- 信息来源区

### 主页入口

- 在现有文档列表页顶部或侧边栏添加「小红书工作台」入口链接

## API

- `GET /api/xhs` — 返回所有文章列表（含元信息）
- `GET /api/xhs/{slug}` — 返回单篇详情（元信息 + 图片列表 + 配文内容）

## 实现约束

- 纯增量，不改动现有文档功能
- 不做编辑/发布功能
- 一键复制配文，方便粘贴到小红书 App
- 图片通过现有静态文件服务提供（需支持子目录）
